# OOPS

## Object Orientation

Object orientation means:

- Point of View
- Perspective
- Alignment

---

## 3 Steps to Follow for These

1. **Identify** - Check if it is an object or not.
2. **Define** - Identify which type of object it is.
3. **Classify** - Identify its properties and behavior.

---

## Example: VK - Cricket Player

VK can be viewed as:

- Good Human
- Good Player
- God
- Good Father

# Real-World Example: House

Before we build a house, we first plan or create a **blueprint** of the house.

~~~text
Plan → House
~~~

A contractor uses the plan to build the house.

~~~text
Plan → Contractor → House
~~~

Similarly, in programming:

~~~text
Class → JVM → Object
~~~

The programmer only gives the instructions. The remaining work is handled by the JVM.
